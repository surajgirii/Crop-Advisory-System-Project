# 🌾 Crop Advisory System

A web-based advisory platform designed to empower farmers by providing tailored crop recommendations based on soil/climatic parameters and delivering real-time Minimum Support Price (MSP) details for major crops.

---

## ✨ Features

* **Crop Recommendation:** Recommends optimal crops based on input parameters (such as soil nutrients, temperature, humidity, and rainfall).
* **MSP Information:** Provides up-to-date Minimum Support Price (MSP) data to help farmers make informed financial decisions.
* **User-Friendly Interface:** Clean HTML/CSS interface tailored for easy navigation.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3
* **Backend:** Python (Flask)
* **Machine Learning / Logic:** Python Libraries (e.g., Pandas, Scikit-learn)
